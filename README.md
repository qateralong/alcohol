# Alcohol

Server-side Fabric mod: ferment drinks in barrels buried in dirt, chain potions and drinks into new ones, and suffer ScreenFX hangovers.

## Features

- Ferment drinks in barrels buried in dirt.
- Chain potions and drinks into new ones.
- Drinking raises your level and triggers ScreenFX hangover effects.
- Farmers Delight compatible.
- Configurable drinks and defaults.

## Commands

`/alcohol` has `give`, `drink`, `level`, `sober`, `export`, `reload` and `debug` subcommands.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
